# RepoPilot 设计说明

## 问题

基线实验中，mini-SWE-agent 成功完成 5/5 个任务，但 4/5 个任务使用整文件覆盖，且 1/5 个任务没有在修改前运行测试。

## 目标

实现安全补丁审计器，对 Agent 的代码修改过程进行验证。

## 核心功能

1. 修改前运行测试并保存结果。
2. 保存源文件快照。
3. 修改后生成文件差异。
4. 检测测试文件是否被修改。
5. 从运行轨迹中检测整文件覆盖命令。
6. 修改后重新运行测试。
7. 输出 JSON 格式评测报告。

## 验收标准

- 测试文件被修改时判定失败。
- 最终测试未通过时判定失败。
- 整文件覆盖操作被准确标记。
- 报告包含修改文件、测试结果和风险信息。
