## 结论边界

这些结果只适用于本仓库内的 5 个小型 Python 缺陷任务，不能直接推断到大型生产仓库。编辑类型识别基于命令文本启发式规则，目前支持 cat 重定向、Path.write_text、open 写模式、sed 和 Perl 替换。
